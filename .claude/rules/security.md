# セキュリティルール

## 絶対にやらないこと
- .env, .env.local, credentials 系ファイルを編集しない
- シークレット・APIキーをハードコードしない
- console.log にセンシティブな情報を出力しない

## データ
- 実データ (顧客名、氏名、メールアドレス、本番の記録) をリポジトリに置かない  
  セッションにも貼り付けない
- テストと動作の確認には、架空のデータを使う  
  メールアドレスは `example.com` のドメインにする
- 手元で実データを扱うときは、git 管理外のディレクトリに置く

## 入力検証
- ユーザー入力は必ずバリデーションする
- SQL はパラメタライズドクエリを使う(ORMが処理する場合はOK)
- HTML出力はサニタイズする

## 依存関係
- 新しいパッケージを追加する前にユーザーに確認する

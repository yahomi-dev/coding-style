# /test-cases — テストケース設計

`/design` で作成した型・関数シグネチャを元に、テストケースを日本語で列挙する。

## 手順

1. `/design` で作成された型定義・関数シグネチャのファイルを読む
2. 各exportされた関数に対してテストケースを洗い出す
3. テストファイルを作成し、`describe` / `it` の構造だけを書く（テストの実装は行わない）

## テストケース設計の方針

- 正常系を先に、異常系・境界値を後に書く
- `it` の記述は日本語で、何を検証するかを具体的に書く
- 1つの `it` で1つの振る舞いだけを検証する
- 入力と期待値のペアが想像できる粒度で書く

## 出力フォーマット

テストファイル（`*.test.ts`）に以下の形式で書き出す:

```ts
import { describe, it } from "vitest";

describe("関数名", () => {
    it("正常系: 〜の場合、〜を返す", () => {});

    it("正常系: 〜の場合、〜を返す", () => {});

    it("境界値: 〜の場合、〜を返す", () => {});
});
```

## ルール

- `it` のコールバックは空にする（テストの実装は `/test-impl` で行う）
- `it` ブロック間には空行を入れる
- import は `vitest` からの `describe`, `it` のみ（`expect` はまだ不要）
- テスト対象の関数の import もまだ不要
- ファイル配置: テスト対象と同じディレクトリに `*.test.ts` として作成

## 注意事項

- このステップではテストの実装を行わない
- ユーザーがケースの過不足をレビューできるよう、ケース一覧を提示する

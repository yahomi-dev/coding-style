# /impl — 本実装（Green）

`/design` で作成したガワに本実装を入れ、テストを通す。

## 手順

1. `/design` で作成された型定義・関数シグネチャのファイルを読む
2. `/test-impl` で作成されたテストファイルを読み、期待される振る舞いを把握する
3. 関数の中身を実装する
4. テストを実行し、全テストが成功（Green）することを確認する

## 実装ルール

- @.claude/rules/typescript.md に従う
- @.claude/rules/design-policy.md に従う
- `/design` で定義した型・シグネチャを変更しない（変更が必要な場合はユーザーに相談する）
- テストを通すための最小限の実装を行う

## 確認事項

以下をすべて実行し、エラーがないことを確認する:

1. `npx vitest run` — 全テストがGreen
2. `tsc --noEmit` — コンパイルエラーなし
3. `npx biome check src/` — lint/formatエラーなし

## 出力フォーマット

1. 実装内容を簡潔に説明する
2. テスト結果を報告する（パス数 / 全体数）
3. 全チェックの結果を報告する

## 注意事項

- テストを通すためにテストコードを修正しない
- 型・シグネチャの変更が必要な場合は、実装前にユーザーに確認する
- 全テストがGreenになったことを確認して完了とする

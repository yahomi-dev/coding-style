# ハーネスエンジニアリング

## ハーネスエンジニアリングとは

AIエージェントを安全・一貫・効率的に動作させるために、エージェントを取り巻く仕組み（ハーネス）を設計する手法。

```
Agent = Model + Harness
```

- **Model**: 知能（LLM本体）
- **Harness**: その知能を実用的にする仕組み全体

ハーネスがなければLLMはただのチャットボット。ハーネスがあることで、自律的に動くコーディングエージェントになる。

## Claude Code のハーネス構成要素

### CLAUDE.md（永続的な指示）

- 全セッションで読み込まれるプロジェクトの指示書
- コードスタイル、ビルドコマンド、アーキテクチャ判断等を記載
- `@path/to/file` で外部ルールファイルを参照可能
- スコープ: グローバル（`~/.claude/CLAUDE.md`）、プロジェクト（`.claude/CLAUDE.md`）

### Rules（整理された指示）

- `.claude/rules/` に配置
- CLAUDE.md から `@.claude/rules/filename.md` で参照
- 常時コンテキストに読み込まれる
- 用途: コーディング規約、設計方針、セキュリティルール等

### Skills（オンデマンドの知識・ワークフロー）

- `.claude/skills/<skill-name>/SKILL.md` に配置
- ユーザーが `/skill-name` で明示的に呼び出したときだけ読み込まれる
- 呼び出すまでトークンを消費しない
- 2種類:
  - **参照型**: 規約、パターン、ドメイン知識（Claudeが必要に応じて参照）
  - **タスク型**: ステップバイステップのワークフロー（`/deploy` 等）

### Hooks（確定的な自動化）

- 特定のライフサイクルイベントで自動実行されるスクリプト
- CLAUDE.mdの指示（助言的）と異なり、**実行が保証される**
- 主なイベント: `PreToolUse`, `PostToolUse`, `Stop`, `SessionStart` 等
- 用途: 自動フォーマット、ファイル保護、通知、環境変数リロード等

### Settings & Permissions

- `.claude/settings.json` で設定
- Claudeが確認なしで実行できる操作を制御
- deny/allowパターンで権限を管理

### MCP（Model Context Protocol）

- 外部サービスとの統合（GitHub、DB、Figma等）
- `.claude/mcp.json` で設定
- Claudeがビルトインツールのように使える

### Subagents（委譲コンテキスト）

- `.claude/agents/<agent-name>.md` で定義
- 独立したコンテキストウィンドウで動作
- 調査、検証、並列作業に利用
- メインコンテキストの肥大化を防ぐ

## 各コンポーネントの使い分け

```
ルールが:
├─ 全セッションで適用すべき?
│  ├─ 情報的（スタイルガイド等）→ Rules / CLAUDE.md
│  └─ 確定的に強制すべき → Hook
│
├─ 必要なときだけ読み込む?
│  ├─ ワークフロー（/deploy等）→ Skill（タスク型）
│  └─ ドメイン知識 → Skill（参照型）
│
└─ 外部サービス連携? → MCP
```

| コンポーネント | 読み込み | 強制力 | 用途 |
|---|---|---|---|
| Rules | 常時 | 助言的 | コーディング規約、設計方針 |
| Skills | オンデマンド | 助言的 | ワークフロー、ドメイン知識 |
| Hooks | 自動 | 確定的 | フォーマット、バリデーション、通知 |
| MCP | 常時 | ツール提供 | 外部サービス統合 |

## ベストプラクティス

### CLAUDE.md

- 「これを外すとClaudeがミスするか？」で判断。Noなら削る
- Claudeがコードから推測できることは書かない
- 長い手順はSkillsに移動してトークンを節約

### Rules

- 短く、具体的に
- 「常に守るべきルール」のみ
- プロジェクト固有のスタイルはここに

### Skills

- 参照型: descriptionでClaudeが「いつ使うか」を判断できるように
- タスク型: 副作用がある場合は `disable-model-invocation: true`
- SKILL.md は500行以内に収める

### Hooks

- 破ってはならないルール（ファイル保護等）はHookで強制
- フォーマッタの自動実行に最適
- 終了コード2でアクション自体をブロック可能
